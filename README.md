# SciOly Lab — Circuit Lab + Thermodynamics (Div C)

Run it locally:
- **Mac:** double-click `start.command` (first time: right-click → Open). **Linux:** `./start.sh`. **Windows:** double-click `start.bat`.
- Or any terminal:  `node server.js`  or  `python3 server.py`  → open http://localhost:8000
- Opening `index.html` directly also works, but progress is saved per address, so use the same one each time.

Start at **Diagnostic**, then follow **30-Day Plan**. Your progress is saved in your browser (Settings → export a backup now and then).

**Important:** the 2027 Thermodynamics device rules (“collect heat”) could not be verified — get the official PDF and paste it into the Rules page. See lessons t16–t18.
